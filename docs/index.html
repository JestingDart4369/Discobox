Discobox

A button-controlled party box on an Arduino Uno R4 WiFi: LED ring and strip effects, a piezo buzzer, MP3 playback, a relay for a spinning disco light, all inside a record-player enclosure.

Work in progress Firmware and electronics run on the bench; the enclosure is in block-out phase.
