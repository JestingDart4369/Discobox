# CAD placeholders

Simple STL models of the parts, for planning the enclosure (space, holes, standoffs). They are **not** the final CAD and **not** exact copies of the parts. Units are mm.

Regenerate them with `python3 cad/make_placeholders.py` (needs `pip install trimesh manifold3d numpy`). Change a number in the script and run it again.

| File | Origin / Z = 0 | Size (mm) | Source |
|------|----------------|-----------|--------|
| `arduino_uno_r4_wifi.stl` | lower-left PCB corner, bottom of PCB | 68.6 x 53.3, about 12.6 high (with jack) | Datasheet ABX00087 section 13: board outline, 4 holes (3.2 mm) at (13.97, 2.54) (15.24, 50.80) (66.04, 7.62) (66.04, 35.56). Header rows and USB-C / barrel jack blocks are approximate. |
| `led_ring_dfr0888_12led.stl` | ring centre, bottom of PCB | OD 47, ID 26, 3.2 high | DFR0888-12 dimension drawing. 12 LEDs (5050, 5 x 5 mm) |
| `dfplayer_mini.stl` | lower-left corner, bottom of PCB | 20.8 x 20.4 x 2.8 | **Typical** value, the manual has no dimensions. Measure yours. |
| `button_16mm_pm161h.stl` | button centre, **top face of the panel** | bezel 21.8 dia, body 16 dia, 23.1 long, cap 11.8 dia | "Little Button" note: hole 16 mm, cap 11.8 mm, size 21.8 x 23.1 mm. How 21.8 / 23.1 split into bezel and length is my reading. Measure yours. |
| `relay_module_1ch_5v.stl` | lower-left corner, bottom of PCB | 50 x 26 x 16.9 | **Typical** 5 V relay module (SRD-05VDC). Measure yours. |

## More files

- `button_pipe.stl`: hollow pipe (26 mm outside, 20 mm inside, 100 mm) with a cap that has a 16 mm hole for the button. Change `PIPE_H`, `PIPE_OD`, `PIPE_ID` in `make_placeholders.py`.
- `cable_clip_test.stl`: one-way cable clip test print (angled slit). Tune `CLIP_CABLE_D`, `CLIP_SLIT`, `CLIP_ANGLE`.
- `blockout_assembly.3mf` / `.stl`: rough block-out of the whole record player (generated by `make_blockout.py`): housing with speaker holes, recessed port pocket, mains compartment, parts, pipe and platter. The 3MF keeps one object per part. The script also checks each part against the P1S bed (256 mm) and lists what has to be split. Edit the numbers at the top of `make_blockout.py` and rerun.
- Design notes: [../doc/ENCLOSURE.md](../doc/ENCLOSURE.md).

Starter model: `Shalplatte_Discobox.3mf` (round 315 mm platter, stem, Arduino holder) is not part of this folder; it is the design starting point.

## Mains part

The relay module carries 230 V on its screw terminals. Keep it, the Swiss plug cable inlet, the fuse and the Type 13 sockets in their **own separate compartment** of the enclosure: its own lid fixed with screws, a wall between it and the low-voltage side, strain relief for the cable, and only the 5 V coil wires and the switched outlet crossing the wall. The 12 V brick can sit in it too, or in the compartment next to it. Dimensions of the brick, buck converter, speakers, sockets and fuse holder are not in the project yet, so there are no placeholders for them.

## Not modelled

Speakers, PAM8403 amp, buck converter, 12 V brick, Swiss sockets, connectors, LED strip. Add them to `make_placeholders.py` when you have the dimensions.

## Interior with wires

`python3 cad/make_interior.py` adds coloured wire tubes to the block-out and renders `interior_top.png` / `interior_iso.png` (also in `doc/img/`). Needs `matplotlib` too.

## Shell and frame

`python3 cad/make_recordplayer.py` / `render_preview.py` add and preview the record-player look (tilted platter, tonearm). `python3 cad/make_full_assembly.py` writes the full coloured 3MF and merged STL (needs `shapely`, `mapbox_earcut`). `python3 cad/make_shell_frame.py` makes the two-part design (PETG frame + lift-off PLA shell + mains lid) and splits shell and frame into quarters that fit the P1S. See [../doc/ENCLOSURE.md](../doc/ENCLOSURE.md).

## 3D viewer and pictures

`python3 cad/make_viewer.py` builds `doc/viewer/discobox_viewer.html` (self-contained WebGL, no internet needed): version tabs, views, shell see-through slider, show or hide groups and single parts (floor, side table, electronics, wires ...). Add a version by adding one line to `VERSIONS` in `make_viewer.py`. `render_scene.py` / `render_preview.py` make the PNG pictures with a z-buffer renderer (`zrender.py`, needs `numba`, `scipy`, `pillow`).
