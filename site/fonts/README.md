# Handwriting font for the journal

Put your own handwriting font here as `handwriting.woff2` (or `handwriting.ttf`) and push; the journal page uses it automatically.
Until then the journal falls back to a script font that is installed on most computers.

How to make a font from your handwriting (free): write the template of https://www.calligraphr.com on paper or a tablet, upload it,
download the font as `.ttf` (or convert to `.woff2`), and name it `handwriting.woff2` or `handwriting.ttf`.
